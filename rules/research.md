# 资料核验与复用

> 触发：未知尺寸、材料和工艺、设备版本、Fusion / MCP API、开源 skill、外部模型或资料冲突。

## 调查方法

- 按具体问题选择关键词和语言；优先查看相关一手资料。证据已充分回答当前问题即可结束，存在缺口或冲突时再扩展语言、来源与搜索范围。
- 技术结论优先来源：实际模型与测量、匹配版本的厂家资料 / TDS、Autodesk API 文档、格式规范、项目作者的源码和测试。社区经验用于发现问题，再用一手资料或试打印核实。
- 打开原始页面，不把搜索摘要、AI 概览、star 数或 skill 自称专业当作证据。
- 数值必须带单位与适用条件：机型、喷嘴、材料系列、方向、层高 / 线宽、单边或直径差、测试方式。机型宣传精度不能直接转为装配间隙。
- 区分通用 FFF 原则与某品牌 / 机型的经验；树脂、粉末等其他工艺参数不得混入当前 FFF 基线。
- 真实产品接口优先按准确型号的工程图、数据表或实物测量。照片只能提供有比例依据的估算，不能产生“精确”配合尺寸；规格尺寸与已有模型的加工补偿分别记录。
- 外部 API 先读本会话工具定义及实际桥接实现，再查匹配版本文档；不得臆造 Fusion 工具名、端口、路径或参数。

## GitHub skill / 模型的选择

- 查实际 SKILL.md / AGENTS.md、引用资料、脚本、提交或发布记录及许可证，记录检查深度；有 README 不代表脚本已验证。
- 优先吸收可核验原则，不为复用切换离开用户指定的 Fusion 主工作流。
- 不照搬固定壁厚、万能公差、未经校准的悬垂检测或单一默认机型。特别检查单位、角度定义、配合间隙和隐式缩放。
- 安装、执行与引用是不同动作。没有任务需要和既有授权时，只读研究，不执行仓库中的安装、上传、打印或缓存清理命令。
- 实际复制或改编文件前核对许可与署名要求；没有明确许可不按可自由复用处理。公开模型的可下载性不代表可商用或可再次发布。

## 形成结论

- 分清官方说明、项目决策、实测结果和待验证假设。冲突优先核对版本、材料与方法差异；会影响关键配合或安全时先解决分歧。
- 临时受阻可换公开来源；无法验证则说明限制，不补造数值。
- 长期有用的直接链接和适用范围进入 [资料入口](references.md)；任务中仅引用关键证据，不额外生成研究报告或复制整篇资料。
