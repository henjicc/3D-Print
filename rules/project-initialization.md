# 初始化与接管

> 触发：首次应用规则、接管工作区、整体调整规则或切换主要设备 / 工艺。

1. 按本次范围检查现有文件、Git 状态和用户约定；涉及模型或应用接管时再检查对应资产与工具，区分模板内容和真实设计资产。
2. 将用户确认的设备、材料、工作流与现场观测写入 [项目上下文](project-context.md)；区分“用户已开启”“工具可见”“读写验证通过”。
3. 只询问会改变设计或工艺的剩余问题。普通尺寸假设可说明后继续，关键配合尺寸、设备配置不得猜测。
4. 裁剪软件项目模板。没有业务代码、网页或开发服务时，删除对应规则，不虚构构建、CI 或启动命令。
5. 长期领域约束进入打印设计、Fusion 操作与验证规则；资料链接集中在资料入口，上下文保留使用入口。所有路由必须指向存在且适用的文件。
6. 规则初始化或重整按用户授权范围执行，持续知识维护见 [规则维护](rule-maintenance.md)；不因此创建模型、安装依赖、修改全局 MCP 配置、初始化 Git 或操作打印机。

完成时核对无占位符、悬空链接和规则冲突；必要未知项写明确认时机与入口，不要求一次填写所有打印参数。
