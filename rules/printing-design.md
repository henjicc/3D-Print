# 面向 FFF / FDM 的打印设计

> 触发：新建、修改、缩放、分件、装配或选材。设备基线见 [项目上下文](project-context.md)。

## 与视觉建模、普通 CAD 的区别

视觉模型可以依赖零厚度面、重叠表面、着色器和贴图表现外观；打印需要真实尺寸、有限厚度和明确的体积边界。普通 CAD 中成立的几何也必须适应逐层成形、材料收缩、方向强度和支撑拆除。圆滑渲染不代表导出网格足够精细，封闭实体也不代表工艺可行。

## 建模前的最少输入

- 明确用途、包络尺寸、关键接口、外观面、装配方式和使用环境。承力件确认力的大小 / 方向、持续时间及固定方式；缺少关键载荷时暂不定案承载能力，继续可独立完成的结构或有边界的原型方案。
- 对接口尺寸记录来源和测量基准；自由设计的尺寸明确为设计值。公制与英制不得混用。
- 先选候选打印方向，再决定需要的分件、支撑及后处理。拆件应有定位、紧固或粘接方案，检查装配工具能否进入。
- 用户偏好尽量一体成型：先比较旋转摆放、结构调整和实机打印空间，能合理合并的固定结构不为排板方便拆成零碎件；保留清洗、维护或制造确实需要的分件。手接触边缘可加轻微倒角，但须保护配合、排水低边及落床面积，并重新检查切片。

## 材料与受力

- PLA 是本项目普通室内模型的默认起点；涉及热、日晒、持续载荷或反复弯曲时，按具体材料数据重新选择。PETG 也不能无条件视作“更强”或满足所有耐热需求。
- 强度检查结合层间结合、壳体连续性、截面、肋板、圆角与受力路径；尽量避免主要拉力剥离层间连接。不用增加填充率代替合理结构与方向。
- 卡扣根部、螺丝柱和受力转角避免突变与薄颈；检查应力集中、螺丝拧紧时的劈裂和长期蠕变。
- 材料含水、冷却与温度会改变结果。按具体耗材厂家指引与真实预设处理，不统一写死 PLA / PETG 的烘干或打印温度。

## 壁厚、底面与细节

- 分开设置几何壁厚、底厚、切片壁层数、顶部 / 底部壳层与填充。CAD 封闭实体允许切片器生成稀疏填充，不等于必须 100% 填充。
- 按实际线宽与壁路径检查薄壁，0.4 mm 喷嘴不意味着每条挤出线宽恒为 0.4 mm。壁厚与线宽整数倍只能作粗估，变线宽算法与路径重叠仍需切片验证。
- 不设全项目通用“最小安全壁厚”。局部薄壁、筋、柱、镂空、文字笔画与凹凸深度须在实际切片中保留下来，承力特征还需实物验证。
- 底面需要稳定落床或明确的支撑 / 筏层方案。朝下的圆角可能形成陡峭悬垂，可按外观和功能改为倒角；不能因此删除需要缓解应力的内圆角。
- 长而薄、大平面、尖角或瘦高结构要检查翘曲、首层接触面积和倒塌风险，必要时调整姿态、分件或 brim。

## 悬垂、桥接与支撑

- 本项目讨论悬垂时统一说明相对竖直方向的角度：0° 是竖壁，90° 是水平悬空面；若引用资料以水平为基准，明确换算。
- 相对竖直 45° 仅可作为初步筛查线索，不是 X2D 或 PLA / PETG 的保证上限。Bambu Studio 的支撑阈值按相对水平坡度定义，不能直接照抄设计角度。
- 区分两端有依托的桥接、一端悬臂和首次出现的孤岛；不得以平均悬垂面积小或桥长小于某固定值就判定无需支撑。
- 优先比较姿态、局部倒角 / 孔顶形状、拆件与支撑方案。横向圆孔要检查孔顶下垂；允许变形时可考虑泪滴孔等自支撑几何。
- 支撑需要有可达的拆除路径和工具空间，关注内腔困住支撑、残留影响配合及外观面损伤。避免把无法取出的普通支撑封进结构。
- 树状支撑不是所有情况的默认最优解；大平面和细碎曲面按实际接触与稳定性选普通、树状或混合方案。
- X2D 使用另一材料支撑前，核对主副喷嘴分工、可达范围、材料相容性、界面 / 主体分配和真实预设。不可把 PLA 与 PETG 混合作为可靠的承力结合。
- 同材支撑与专用 / 异材支撑的 Z 间距不同，不统一设为零。拓竹 PLA Basic 与 PETG HF / Basic 互相支撑教程仅适用其指定组合；其他系列或品牌须另查并试打。

## 配合、孔与紧固

- 将设计间隙、尺寸允许偏差和打印补偿分开。明确滑动、定位、卡扣、过盈或胶接需求，不给所有接口一个“公差”。
- 单边间隙记为 c：圆孔与轴直径差为 2c。说明补偿改的是半径还是直径；盲孔还要核对深度和底部余量。
- 检查孔轴方向、象脚、接缝、首层挤压和收缩对配合的影响。不要对全部尺寸统一增加“孔补偿”，也不要同时在 CAD 与切片器重复补偿。
- 螺丝、螺母、热熔嵌件、轴承和磁铁按具体规格设计；区分通孔、自攻底孔、嵌件安装孔和直接打印螺纹。打印螺纹必须有真实牙形，不能仅靠外观标记。
- 模型整体改尺寸时，默认保护固定硬件接口的直径、深度和必要安装空间，并重新检查孔周余量；用户明确要求同步缩放接口时例外。
- 一体打印活动结构分别检查 XY 与 Z 间隙、首层连桥、支撑干涉和释放方式。精密配合、新材料或反复受力卡扣先设计小样，验证后再冻结配合尺寸；等待实测时继续其余设计并交付小样与具体测量项。

## 几何与颜色

- 每个计划打印的独立零件要有合法体积；避免零厚度、自相交、意外内部面、重叠实体和意外孤立部分。开口容器也需要封闭的壁体边界，不是把容器口盖住。
- 组件、实体和实际打印件一一核对；多件或多材料模型不得误布尔合并成一件，也不能只导出可见的某一部分。
- 外观颜色不等于实际耗材分配。多色任务核对对象、材料映射、换料成本、塔与支撑；不用纹理渲染证明打印能还原外观。
