# 验证、切片与交付

> 触发：Bambu Studio 操作、模型进入稳定状态、导出、准备交付、试打印反馈或结束规则修改。

## 按交付内容选证据

| 层级 | 必须检查 | 可以宣称的结果 |
|---|---|---|
| 规则调整 | 文件内容、相对链接、路由覆盖、已确认事实、无模板占位与冲突 | 规则已更新 |
| CAD | 正确文档 / 修订、关键参数、实际尺寸、特征状态、实体数与有效几何、必要截面和多视角 | CAD 已检查 |
| 导出 | 文件非空可读、单位与包络匹配、对象完整、网格封闭与缺陷、曲面 / 小特征保持 | 导出文件已检查 |
| 切片 | 正确机型 / 喷嘴 / 材料 / 打印板配置，实际完成切片并检查路径 | 切片检查通过 |
| 实物 | 完成打印、测量关键尺寸、装配与用途验证，记录材料和实际设置 | 对已验证条件的实物验证通过 |

较早一层不能证明后续层通过。没有实际切片时说明“待切片验证”；没有实物证据时说明“未试打印”。工具返回成功、正体积或漂亮预览都不能单独证明模型可打印。

## 检查范围与停止条件

- 按本次交付和变更影响选择检查：规则文字检查内容、链接与冲突；几何修改检查受影响特征、关联结构及相关派生产物；材料或姿态修改重新检查切片、支撑和受力条件。
- 完成适用检查并修复本次问题后即可交付；仅有新变化、失败或未解决疑点时扩大或重复检查，不重复无关验证。
- 等待关键实测时，可完成原型、小样及测量项，明确尚未冻结的配合；等待不阻塞无关部分，也不能将未实测结果宣称为最终适配。

## CAD 与网格检查

- 与用户要求逐项核对外形、孔径 / 孔距、腔体、壁厚和配合；检查局部薄弱处，不能用总体积 / 包络体积比推断最小壁厚。
- 正体积、实体数量、网格封闭等检查各有边界；结合零厚度、自相交、退化面、法线、内部面与独立连通部分检查，不以单一指标代替几何有效性。
- 多视图检查外形，剖面与数值检查内部和配合。自动修复后重新测量，不能让切片器静默删掉特征后宣称完成。
- 修改参数后重新计算受影响特征、测量并保存；孔位、抽壳与圆角等依赖不得停留在旧状态。

## Bambu Studio 操作

- 先识别正在运行的实例、应用路径、当前项目、登录与打印机连接状态，优先复用用户已登录的窗口。某个窗口未登录不能证明其他实例也未登录；不要为排障直接再启动一个 GUI，也不擅自关闭其他窗口或丢弃未保存项目。
- 命令行用于离线切片、导出与参数检查；界面用于回开、预览和用户交接。独立 `--datadir` 的离线配置不代表已登录 GUI 的账号与设备状态。命令行任务须带完整切片 / 导出参数，结束后确认进程退出，不让它变成额外 GUI 实例。
- 界面操作后读取新状态；点击未触发时先刷新，仍无变化就改用可访问的菜单或经当前软件确认的快捷键，不连续盲点。不得复用旧窗口坐标或元素编号。2.8.2.61 本机帮助菜单已确认 macOS `⌘R` 为切片单盘；后续版本重新核对，不能与打印快捷键混淆。
- 完成标准是当前正确项目出现切片结果与预览，不是点击动作返回成功。需要用户手动打印时，停在可检查的预览页并说明项目、材料和估算；实机授权边界见 [安全边界](security.md)。

## 切片检查

1. 从当前软件读取真实 X2D、喷嘴、材料系列和打印板预设；缺少正确机型预设时不借用相似机型或编造配置以生成机器指令。区分用户确认的耗材、AMS / 外置料架配置和项目预设；颜色不能确定系列，`Generic PETG` 仅说明当前通用预设，不能冒充已识别品牌。采用通用预设时明确未知信息与适用边界，换料后重新切片。
2. 检查导入单位、对象数量、方向、落床和有效空间。支撑、brim、擦拭塔、主副喷嘴区域及逐件打印的运动间距一起计算。
3. 完成切片后查看逐层预览：首层、孤岛起始层、孔顶 / 桥接、薄壁 / 文字、腔体封顶、卡扣及配合处；确认连续挤出路径与需要保留的间隙。
4. 检查支撑接触、可拆除性、内腔困支撑、材料分配、接缝与关键外观面。告警需要解释和处理，不能仅以“切片无报错”为通过标准。自动截面对照须匹配实际模型层高并区分支撑层；突变处可检查相邻模型层，但相邻层有覆盖本身不证明通过，还须核对封顶连续性、缺口、实际端面偏差及关键尺寸容许值。无法解释的差异保留为未解决项，不靠放宽阈值消除告警。
   对狭缝、小角落和配合槽，优先评估“仅在打印板生成支撑”“仅支撑关键区域”和适度增大支撑 XY 间距；它们不保证消除窄处支撑，也不能作为所有模型通用的固定预设。逐层查看仍伸入角落的支撑，必要时局部屏蔽或修改自支撑结构；最终保留的支撑必须有实际夹取和退出空间。材料或姿态改变时重新核对，不把一次试打参数当作普遍保证。
5. 报告预估时间、材料用量与必要支撑；明确它们来自切片估算，不能写成已实际消耗。
6. 实际切片器不可访问时交付已验证的 CAD / 网格与具体待检查项，不伪造已切片的项目或 G-code。已生成的 G-code 仅适用于该机型及配置，源模型或配置变化后重新切片。
7. 命令行生成的项目在实际 GUI 回开核对机型、材料、逐板板型、自定义工艺、摆放、预计时间和用料；明显差异先查配置继承或设备同步，再重新切片。全局板型卡片与逐板设置不一致时，以该板生效配置及实际切片温度交叉核对，不凭一张卡片判断。
8. 区分普通保存项目与导出含路径的切片文件；不要仅凭 `.3mf` 后缀宣称含 G-code，交付前检查包内实际内容及可读性。遇到回开恢复默认参数时，先核对同版本预设继承、工艺差异标记和逐板设置；仅为保留已确认配置修正元数据，随后回开验证，不修改机器动作或盲目照搬其他版本字段。

## 试打印与反馈

- 新配合、孔补偿、打印螺纹、卡扣或一体活动件，优先用与实际结构同方向、同材料和同配置的小样验证；标定方块不能替代所有孔与配合测试。
- 小样记录名义尺寸、实测尺寸、间隙定义和装配手感；局部补偿与全局缩放分开，不把一次结果泛化到其他材料 / 方向。
- 失败先区分设计、姿态 / 支撑、切片参数、材料状态与设备问题。一次优先改变一个主要变量，保留修订与结果，不能无证据反复加温、加填充或改所有参数。
- 用户反馈可以作为实物证据，但明确来源，不宣称代理自行测量。尺寸通过不等于长期承载或寿命已验证。

## 交付要求

- 提供实际存在的原生设计位置与已生成文件链接；必要时提供真实模型预览。给出关键尺寸、材料、放置面与支撑建议。
- 简述实际检查、失败或未验证项、需要的小样和本次版本保存情况。无需为不相关的软件测试或构建编造检查。
- 纯规则改动仅验证规则；任务包含 MCP 连接核验 / 恢复时，按已授权的 [Fusion 恢复流程](fusion-mcp.md) 操作。交付只报告与本任务有关的状态。
- 实际建模任务按事实说明 Fusion 文档保存、导出与切片状态；不要用软件服务“已启动”替代模型交付状态。
